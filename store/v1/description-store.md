## Description longue

### FR

**Tarot Divinatoire** est un site éditorial consacré aux 78 lames du Tarot de Rider-Waite-Smith (illustrations du domaine public) : significations, associations, tirages interactifs et mode apprentissage, dans une application PHP autonome dont les données vivent dans un vault SQLite.

#### ✨ Fonctionnalités clés
- **78 cartes** — 22 arcanes majeurs + 56 mineurs (Bâtons, Épées, Coupes, Deniers), toutes visibles à l'accueil
- **Fiches éditoriales** — identité, carte du jour, Amour, Travail, Finances, Guidance, signification et description
- **Associations** — combinaisons entre lames dans un panneau repliable
- **Tirages interactifs** — plusieurs dispositions intégrées
- **Mode apprentissage** — quiz QCM type flashcards (Leitner simplifié), progression conservée localement
- **Recherche plein écran** — filtrage instantané par nom ou numéro, filtres par famille
- **Nuances** — pense-bête comparant les lames aux thèmes proches
- **Partage par URL** — chaque lame a son adresse (`?carte=…&deck=…`), aperçu Open Graph dans WhatsApp/iMessage
- **Arcana Index** — bibliothèque 3D Three.js en rayonnages par famille et numéro (v11 expérimental)
- **Autonome** — application PHP + contenu embarqué dans un vault SQLite, sans build

### EN

**Tarot Divinatoire** is an editorial site devoted to the 78 Rider-Waite-Smith Tarot cards (public-domain illustrations): meanings, associations, interactive spreads and a learning mode, in a self-contained PHP application whose data lives in a SQLite vault.

#### ✨ Key features
- **78 cards** — 22 major + 56 minor arcana (Wands, Swords, Cups, Coins), all visible on the home page
- **Editorial sheets** — identity, card of the day, Love, Work, Finances, Guidance, meaning and description
- **Associations** — card combinations in a collapsible panel
- **Interactive spreads** — several built-in layouts
- **Learning mode** — multiple-choice flashcard quiz (simplified Leitner), progress kept locally
- **Full-screen search** — instant filtering by name or number, family filters
- **Nuances** — reminder comparing cards with neighboring themes
- **URL sharing** — every card has its own address (`?carte=…&deck=…`), Open Graph preview in WhatsApp/iMessage
- **Arcana Index** — dense Three.js library shelved by family and number (experimental v11)
- **Self-contained** — PHP app + content embedded in a SQLite vault, no build
